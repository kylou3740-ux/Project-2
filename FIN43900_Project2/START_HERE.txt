Project 2 quick start

1) Extract the folder and open it in VS Code.
2) In PowerShell: py -m venv .venv
3) Activate: .venv\Scripts\Activate.ps1
4) Install: pip install -r requirements.txt
5) Test: python -m unittest discover -s tests -v
6) Run app: python -m streamlit run app.py

Read README.md and docs/ before submission. Complete the Locked Changed-Input prediction independently, without AI, and commit it BEFORE the test run. Do not claim manual tests, cold runs, AI checks, or video transcripts that have not actually occurred.
